#  AI Virtual Assistant (JARVIS-Style)

A mind-blowing **JARVIS-style AI Virtual Assistant** built using the **MERN Stack**, capable of voice-based interaction, intelligent AI responses, secure authentication, and full personalization.  
The application is **fully deployed for free on Render** and optimized for mobile and desktop devices.

---

##  Project Overview
- **Project Type:** Full-Stack AI Web Application  
- **Tech Stack:** MERN + AI + Voice APIs  
- **Deployment:** Render (Free Tier)  
- **Purpose:** To create an intelligent, customizable virtual assistant that can talk, think, remember users, and adapt to branding needs.

---

##  Key Capabilities
The assistant can:
- 🗣️ Talk like a real assistant using **Web Speech API**
- 🧠 Generate smart responses powered by **Gemini AI**
- 🔐 Remember users with **JWT + bcrypt authentication**
- 🎨 Use custom images via **Cloudinary + Multer**
- 🧩 Be fully customized (name, branding, and voice)

---

## ✨ Features
- Voice input & output (real-time speech interaction)
- AI-powered conversational responses using Gemini
- Login & Signup authentication system
- Secure password hashing with bcryptjs
